# Loops Donor Emails

After each campaign, it surfaces opens, clicks, and replies — and flags donors whose engagement is climbing.

## Prerequisites
- A [Loops](https://loops.so) account with an API key (`LOOPS_API_KEY`) and your donor list/segments configured
- A Slack workspace where you can install the agent's bot and invite it to one or more channels
